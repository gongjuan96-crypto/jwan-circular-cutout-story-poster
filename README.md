## ✨ 功能效果
- 输入一张个人照片，生成艺术感故事海报
- 使用原始照片中的局部细节制作圆形照片切片
- 结合艺术撞色纯色块与真实照片
- 圆形元素小尺寸、不规则散落，保留大面积留白
- 根据照片氛围自动匹配背景颜色，也支持指定颜色
- 适配朋友圈、小红书、抖音等社交媒体配图

## 🛠️ 如何安装和使用本 Skill
### 方式一：复制完整内容导入
适用于支持 Skill 导入的大多数 AI 平台。
1. 打开本仓库中的 `skills/circular-cutout-story-poster/SKILL.md`
2. 点击文件右上角的 **Raw**
3. 全选并复制全部文本
4. 打开支持 Skill 能力的 AI 工具，进入技能导入界面
5. 将文本粘贴到导入框并确认导入
6. 上传个人照片，调用 `circular-cutout-story-poster` 生成海报
### 方式二：下载文件本地导入
1. 打开 `skills/circular-cutout-story-poster/SKILL.md`
2. 点击右上角 `···`，选择 **Download file**
3. 将下载的 `SKILL.md` 导入 AI 工具的技能面板
4. 上传照片并调用本 Skill 生成海报
## 📌 调用示例
text

￼
也可以补充主题、文案、颜色或构图要求：
text
$circular-cutout-story-poster，旅行主题，使用蓝橙撞色，加入一句简短英文文案。

## ⚠️ 使用注意事项
1. 本 Skill 需要图片输入，请先上传一张个人照片
2. 生成效果会受到原图构图、光线和清晰度影响
3. 如需调整，可以补充颜色、主题、文案或构图要求
4. 生成图片可直接保存，也可以根据不同社交平台进行二次裁剪
